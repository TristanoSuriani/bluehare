## 6. Extended Micro-Phonetic Tokens

Non-standard phonetic dictionary entries designed to map directly to synthesized micro-vocalizations, glottal transients, and data streams:

| Orthographic Token | Target Pronunciation Mapping | Intended Acoustic Function |
| --- | --- | --- |
| `DAT_01` | `D AE1 T _ CLK` | Unvoiced dental transient / clocking click |
| `GLITCH_IMPULSE` | `G L IH1 T S _ PLS` | Rapid plosive burst without vowel release |
| `SUB_BURST` | `S AH1 B _ GLO` | Low-frequency glottal stop / sub-bass marker |
| `0x4F` | `Z IH1 R OU _ EH K S _ F AO1 R _ EH F` | High-speed hexadecimal stream |
| `SINE_110` | Continuous `/a/` vowel at fixed 110 Hz pitch | Monotone melodic carrier unit |
| `SINE_220` | Continuous `/i/` vowel at fixed 220 Hz pitch | Mid-frequency tonal carrier unit |
