# The component registry (2026-10-17, the architecture's item 3): everything a distribution can pick, one a line:
#   KIND  NAME  LAYER  FILES  ID  SUB  | WHAT | CREDIT
# KIND: ENGINE, FX (an effect beside the baseline's fixed chain), PLUGIN (a player on top of the engines), UI (a part of
# Blue Hare OS's screens). LAYER: baseline, os, fm1 (the directories under firmware/). FILES: comma-separated, in that
# layer's directory. ID and SUB, an engine's only ("-" for the others): its stable id (the stores' and the protocol's,
# never reused, never an archived one's: firmware/baseline/engine_ids.h ARCHIVED) and its substitute (the engine a sound
# of it loads as in a distribution without it). tools/gen_dist.py checks all of it, writes the ENGINE lines engine_ids.h
# includes (build/gen/engines_registry.h) and gives the build BLUEHARE_<KIND>_<NAME> 0 or 1 by what a distribution
# (distributions/*.txt) picks: its engines by name, its FX, PLUGIN and UI on lines `FX <NAME>` .. (none of a kind: all
# of it). The credits table in AUTHORS.md ("Components in the build") is generated from here (make tables).
