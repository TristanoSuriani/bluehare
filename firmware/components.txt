# The component registry (2026-10-17, the architecture's item 3): everything a distribution can pick, one a line:
#   KIND  NAME  LAYER  FILES  | WHAT | CREDIT
# KIND: ENGINE (its id and substitute: firmware/baseline/engine_ids.h), FX (an effect beside the baseline's fixed chain),
# PLUGIN (a player on top of the engines), UI (a part of Blue Hare OS's screens). LAYER: baseline, os, fm1 (the
# directories under firmware/). FILES: comma-separated, in that layer's directory. A distribution (distributions/*.txt)
# lists its engines by name, and its FX, PLUGIN and UI components on lines `FX <NAME>` .. (none of a kind: all of it);
# tools/gen_dist.py checks each against this file and gives BLUEHARE_<KIND>_<NAME> 0 or 1 to the build. The credits
# table in AUTHORS.md ("Components in the build") is generated from this file (tools/gen_dist.py --credits).
